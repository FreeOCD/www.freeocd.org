# Security Policy

## Supported versions

Only the currently deployed site (the `main` branch) is supported.

## Reporting a vulnerability

Please [report vulnerabilities privately on GitHub](https://github.com/FreeOCD/www.freeocd.org/security/advisories/new).
Do not include vulnerability details in a public issue or pull request.

We will acknowledge receipt within 5 business days and aim to publish a fix
within 30 days, coordinated with a GitHub Security Advisory where appropriate.
